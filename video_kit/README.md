# キャラ差し替え版ショート動画キット

元動画（縦型 576x1024・約2分20秒・約34カット）の**構成とテンポ**をそのままに、別のキャラで作り直すためのキットです。

## 元動画の構成（分析結果）

| パート | 時間 | 内容 |
|---|---|---|
| フック | 0〜3秒 | 「繁盛店が利益ゼロの理由」— 結論を先に見せる |
| 状況説明 | 3〜23秒 | 12店舗・純利益8億円 → 税金で2億円取られる |
| 転 | 23〜56秒 | フェリーで島へ → 会社を登記 → ブランド権利を持たせる |
| 仕掛け | 56〜75秒 | ライセンス料8億円を請求・送金 |
| 結果 | 75〜104秒 | 調査が来ても利益0円・税金0円 |
| 解説 | 104〜122秒 | 「IPホールディング」の仕組みを図で説明 |
| 締め | 122〜137秒 | 実例の示唆 → 「知りたいならフォロー」 |

- 1カット 2〜7秒。ナレーション1文 = 画像1枚
- 画面下にナレーションの要点を短い字幕で表示（数字やキーワードは黄色）
- 背景は紺色＋暖色、モブキャラは顔のないグレーの人型で統一し、主人公だけ目立たせている

## ファイル

| ファイル | 内容 |
|---|---|
| `character.json` | キャラ名・見た目（英語）・画風。**ここを書き換えればキャラが変わる** |
| `scenes.csv` | 全34シーン：秒数・ナレーション・字幕・画像プロンプト（`{CHAR}` がキャラ名に置き換わる） |
| `prompts.txt` | 画像生成AIにそのまま貼るプロンプト（自動生成） |
| `script.txt` | 音声合成・読み上げ用の原稿（自動生成） |
| `make_video.py` | 画像と音声から動画を組み立てるスクリプト |
| `original_transcript.txt` | 元動画の書き起こし（参考用・自動文字起こしなので誤字あり） |

## 手順

1. **キャラを決める** — `character.json` の `name` / `name_en` / `description_en` を書き換える（今は例として「むぎ（柴犬）」）。
   見た目の説明は毎シーンに入るので、服装・色・体型まで具体的に書くとキャラがブレにくい。
2. **プロンプト出力** — `python3 make_video.py prompts`
3. **画像を作る** — `prompts.txt` を画像生成AI（Midjourney / ChatGPT / Gemini など）に投げ、9:16 で生成して
   `images/01.png` 〜 `images/34.png` として保存。
   コツ：最初にキャラの立ち絵を1枚作り、それを参照画像（キャラ参照 / image reference）にして全シーンを作ると統一感が出る。
4. **ナレーション** — `script.txt` を VOICEVOX や ElevenLabs などで読み上げ、
   - シーンごとに `audio/01.mp3` 〜 `audio/34.mp3`（推奨：尺が自動で合う）、または
   - 1本にまとめた `narration.mp3`（この場合 `scenes.csv` の `sec` 列で尺を調整）
   - 任意で `bgm.mp3` を置くと小さめの音量で重なる
5. **書き出し** — `python3 make_video.py build` → `output.mp4`
   （ffmpeg が必要。字幕フォントは `character.json` の `font` で変更可）

画像や音声が足りなくても仮画面・無音で書き出せるので、先に尺やテンポだけ確認することもできます。

## 注意

- ナレーションは元動画の丸写しではなく、同じ流れで言い回しを書き直しています。元動画のキャラ・ロゴ・ブランド名（BURUGORI 等）は使わないでください。
- 内容は税務スキームの話なので、「イギリスで実際に…」等の事実の部分は投稿前に確認するのがおすすめです。
